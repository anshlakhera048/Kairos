# Kairos v1.0 — Agent Arena

*TradingAgents, but the market is real.*

Every viral agent-trading repo runs on toy fills. Kairos v1.0 is the
opposite bet: a real deterministic matching engine, honest fill modeling,
and one-command everything — packaged so a stranger goes from `pip
install` to a running bot tournament in two minutes.

## What's in v1.0

**Install & play**
- `pip install kairos-engine` → `kairos demo`: 10-seed tournament on the
  deterministic C++ engine, ranked leaderboard in your terminal.
- `kairos arena`: full tournaments (`--bots`, `--seeds`, `--regime`,
  `--out` JSON, `--html` leaderboard page).

**Build a bot**
- Python bots compete on the real engine:
  `kairos arena --py-bot mybot.py:MyBot` — same seeds, same market, one
  leaderboard as the C++ bots.
- `kairos.agents`: `ArenaBot` base, stdlib-only LLM client
  (`KAIROS_LLM_API_BASE/KEY/MODEL`), deterministic `MockLLM`, and
  `DebateTrader` — analyst → bull/bear debate → trader → rule-based risk
  gate. `examples/debate_demo.py` runs without an API key.
- Claude Code skill: `.claude/skills/kairos/SKILL.md` — clone the repo,
  ask Claude to build you a bot. Every command in it was validated.

**Trust the numbers**
- `kairos realism-gap`: the headline finding as one command. Same
  strategy, same data, four fill-honesty levels — naive fill-at-touch
  overstates market-maker PnL by ~19-30% vs the risk-averse queue model.
  `--chart` renders the equity curves as SVG.
- 92/92 tests green, ASan/UBSan clean, differential-tested engine
  (~18M adversarial ops vs a naive reference).

**Compete**
- `kairos season run season-01` / `kairos leaderboard`: published
  season configs, append-only ledger committed to the repo — every
  score re-runnable and verifiable.
- Season 1 (Genesis) recorded: 20 seeds × 30s, calm. `fixed` 0.7886
  edges out `as` 0.7885 — one disqualified seed cost the A-S bot the title.

## The honest fine print

- Synthetic data throughout the demos: the *relative* realism gap is the
  finding; absolute PnL is not tradable.
- Python strategy callbacks are ~11.6× slower than C++ (measured) —
  fine for research, measure before you trade on it.
- Nothing here places real orders. The recorder is read-only market data.

## Try it

```bash
# wheel attached to the GitHub release, or build from source:
pip install kairos_engine-1.0.0-cp312-cp312-linux_x86_64.whl
kairos demo
kairos realism-gap --chart gap.svg
kairos season run season-01
```
